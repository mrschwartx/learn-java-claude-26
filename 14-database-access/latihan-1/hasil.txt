== 3. SQL injection: input berbahaya  x' OR '1'='1 ==
  SQL hasil rakitan : SELECT nama FROM pelanggan WHERE nama = 'x' OR '1'='1'
  Konkatenasi mengembalikan : 4 baris (SEMUA pelanggan bocor)
  PreparedStatement mengembalikan : 0 baris (dicari literal nama itu)
  Konkatenasi dengan '1; DROP TABLE korban; --' -> tabel korban masih ada? false
  PreparedStatement dengan nilai yang sama -> ditolak server (nilai bukan bilangan bulat) (SQLState 22P02), tidak ada yang dieksekusi
