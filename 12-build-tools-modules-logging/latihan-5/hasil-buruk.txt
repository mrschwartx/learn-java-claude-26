== 1. Konkatenasi vs parameterized (level DEBUG NONAKTIF) ==
  konkatenasi : toString() dipanggil 1000 kali dari 1000 log
  parameterized: toString() dipanggil 0 kali dari 1000 log
  argumen hasil perhitungan mahal + guard isDebugEnabled(): dihitung 0 kali

== 2. Data sensitif ==

{"level":"INFO","logger":"LogBuruk","requestId":null,"msg":"BAIK  login user=andi kartu=****5678"}
